# Tic-Tac-Toe AI

A Python-based Tic-Tac-Toe game featuring an AI opponent powered by the Minimax algorithm.

## 🎯 Project Goals

- Build a playable Tic-Tac-Toe game using Python.
- Implement game logic and win detection.
- Develop an AI opponent.
- Explore the Minimax algorithm and adversarial search.

## 🧠 AI Concepts

- Game trees
- State-space search
- Minimax algorithm
- Adversarial search
- Decision-making

## 🛠️ Technologies

- Python
- Git
- GitHub
